# SyncTune

A local-first music player with synchronized listening rooms.

## Vision

SyncTune lets people organize local music, import playlist metadata
from supported sources, and listen together in synchronized rooms
on a local network.

## Planned clients

- Desktop: Tauri + React + TypeScript
- Web: React + Vite + TypeScript
- Server: Node.js + Express + Socket.IO
- Persistence: SQLite

## Principles

- Local-first music playback
- Server-authoritative room state
- Timestamp-based playback synchronization
- Authorized music sources only
- No mandatory cloud backend

## Status

Early development. Architecture and repository scaffolding are
the first milestone.
